# `ttk`

`ttk` is a toolkit for building quickly building consistent TUI interfaces.

## LLM Usage

AI was not used for planning, architecturing, writing, or otherwise creating the Rust API. However, the Lua bindings were generated with an LLM. The LLM-generated code resides exclusively in `lua.rs` - no other file was changed, intentionally or inadvertently, by the agent in the process.
